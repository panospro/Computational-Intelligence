# 🧠 Computational Intelligence Projects

A collection of projects exploring fuzzy logic, control systems, and adaptive intelligence techniques.  
These assignments were developed as part of a university course on **Computational Intelligence** and involve both simulation and control-oriented problem solving.

---

## 📘 Projects Overview

### 📌 Project 1: Fuzzy PI Controller
Designed a fuzzy PI (Proportional-Integral) controller to regulate system behavior using fuzzy logic rules.  
Emphasis was placed on comparing fuzzy vs. classical control response.

### 📌 Project 2: Fuzzy-Based Car Control
Simulated a fuzzy system that controls a vehicle's direction and speed based on its position and orientation.  
Involved multi-input fuzzy inference, rule tuning, and real-time feedback behavior.

### 📌 Project 3: Air Conditioning System with Fuzzy Control
Modeled a fuzzy logic-based air conditioning system that adjusts room temperature dynamically.  
Explored membership functions, defuzzification strategies, and environmental factors.

### 📌 Project 4: Elevator Controller Using Fuzzy Logic
Built a fuzzy controller to manage elevator behavior based on current floor, request frequency, and direction.  
Prioritized smooth operation and responsiveness using fuzzy rule sets.
